# Limitless Sweet 🌻

> **Cafetería Temática & Repostería Inclusiva**  
> Ubicación: Av. José Larco 743, Miraflores, Lima, Perú.

Limitless Sweet es una plataforma web para una cafetería temática especializada en repostería artesanal para personas con alergias e intolerancias alimentarias (100% libre de gluten, opciones veganas, sin azúcar y sin lácteos).

---

## ✨ Características Principales

- **Tema del Mes Dinámico:** Experiencia visual adaptada a la temática mensual actual (*Flores Amarillas*).
- **Menú Inclusivo y Filtros en Tiempo Real:** Filtrado instantáneo por alérgenos y preferencias (`Sin gluten`, `Vegano`, `Sin nueces`, `Sin azúcar`, `Sin lácteos`).
- **Estados de Disponibilidad:** Manejo de postres disponibles, temáticos y productos agotados con interacción adaptada.
- **Transparencia Total de Insumos:** Acordeón con la lista detallada de insumos, proveedores auditados y certificaciones oficiales de no-trazas.
- **Sistema de Reservas y Contacto:** Formulario interactivo con validación estricta (Zod + React Hook Form), feedback visual con microinteracciones y confirmación modal.
- **Integración con WhatsApp y Teléfono:** Botones directos con prefijo de Perú (`+51`).
- **Aviso Legal Obligatorio:** Cumplimiento de normativas de seguridad alimentaria y prevención de contaminación cruzada.

---

## 🛠️ Stack Tecnológico

- **Framework:** Next.js 15 (App Router)
- **Lenguaje:** TypeScript
- **Estilos:** Tailwind CSS
- **Animaciones:** Framer Motion
- **Formularios & Validación:** React Hook Form + Zod
- **Iconografía:** Lucide React
- **Microinteracciones:** Canvas Confetti

## 🚀 Instalación y Uso Local

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/FabrizioV22/LimitlessSweet.git
   cd LimitlessSweet
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```
   Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

4. **Compilar para producción:**
   ```bash
   npm run build
   npm run start
   ```
